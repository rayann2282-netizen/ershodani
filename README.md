# ارشدني (Ershodani)

يرتب لطالب نظم المعلومات في جامعة الإمام مواد ترمه الجاي، ويحسب له المعدل اللي يحتاجه، من جواله.

**جرّبه:** https://ershodani.vercel.app

## المشكلة

قبل التسجيل، الطالب يحتاج يقارن خطته الدراسية بالمواد اللي خلّصها، ويتتبع المتطلبات السابقة بنفسه، ويحسب معدله بيده. كثير منهم يضيعون أو يروحون للإرشاد الأكاديمي بس عشان يعرفون وش ينزلون.

## وش يسوي الحين

- يقرأ ملفين من الخدمات الذاتية (كشف المقررات المتبقية والسجل الأكاديمي) داخل المتصفح، والملف ما ينرفع لأي مكان.
- يعرض المواد اللي خلّصها، والطالب يأكدها أو يصلحها.
- يرتب الخطة: المتأخرة أول، بعدها مواد مستواه، ويكمّل من المستوى اللي بعده لين ١٩ ساعة.
- يوضّح المواد المقفلة وليش انقفلت، ومتى تنفتح.
- يخلي الطالب يختار حمله (خفيف ١٢، متوسط ١٥، ثقيل ١٩)، ويختار متطلباته الجامعية.
- يقدر يشيل مادة من خطته، بعد ما يوريه وش المواد اللي بتتقفل عليه بسببها.
- يحسب المعدل اللي يحتاجه هالترم عشان يوصل لهدفه (من ٥).
- يحفظ الخطة صورة.
- يحفظ تقدم الطالب في حسابه (إيميل وكلمة مرور، أو قوقل).
- يوقف لو الملفات لتخصص غير نظم المعلومات.

## الجاي

- تخصصات وكليات ثانية.
- تحديد المواد يدوي لو ما عنده الملفات.
- فتح الدخول بقوقل للكل (الحين لإيميلات محددة بس).
- حماية من التسجيل الجماعي (CAPTCHA)، وتأكيد الإيميل.
- مراجعة المتطلبات السابقة للمستوى ٤ و٥ مع القسم.

## مبني بـ

- **React 19** + **Vite 8**: الواجهة
- **React Router 8**: رابط لكل شاشة
- **Supabase**: قاعدة البيانات (Postgres) وتسجيل الدخول، وكل طالب يوصل لبياناته بس (Row Level Security)
- **pdfjs-dist**: قراءة ملفات PDF داخل المتصفح
- **html-to-image**: حفظ الخطة صورة
- **Vitest**: اختبارات حساب الخطة والمعدل وقراءة الملفات
- **Vercel**: النشر

## شغّله على جهازك

تحتاج Node.js ومشروع Supabase.

1. شغّل ملفات `supabase/migrations/` بالترتيب (`0001` لين `0004`) في **SQL Editor** في Supabase.
2. داخل مجلد `web/`، انسخ `.env.example` باسم `.env.local`، وحط فيه قيم مشروعك:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY` (المفتاح العام publishable بس، أبدًا مو المفتاح السري)
3. شغّل:

```bash
cd web
npm install
npm run dev
```

أوامر ثانية (داخل `web/`):

```bash
npm test          # الاختبارات
npm run build     # نسخة للنشر في dist/
npm run preview   # تشوف نسخة النشر على جهازك
```
